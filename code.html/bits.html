Marks file format guidance

The Excel file should contain exactly three columns: BITS ID, Course and Total Marks.

Total Marks must be whole numbers from 0 to 100. Fractional, blank or out-of-range rows are flagged and left out of grading until corrected.

Students who did not appear for the examination (NC grade) should not be included. This console grades only students who appeared.
